Simple Flag designs for the kerbal space program Archipelago Randomizer.
I wont stop anyone for using them in vanilla KSP. :) 


## Now also contains the Map Pack used by [Universal Tracker](https://github.com/FarisTheAncient/Archipelago/releases)

Simply download `UT.Maps.zip` from the release page and save it somewhere you remember.\
UT will ask for a Map pack on first connection to a KSP slot.

If UT does not ask for it use `/reload_pack` to show the prompt again.\
If you get any error see if Universal Tracker is up to date.


The svg files in here where fully created by hand in inkscape.
However, the font "Nasalisation" was used for text, which is free to use, but is not allowed to shipped independently.
You can find it here: https://www.dafont.com/nasalization.font, in case you want to make further edits.
